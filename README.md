# Campus Customs: store website and chatbot (HW4)

Everything for the homework is in **[`hw4/`](hw4/)**. Start with [`hw4/README.md`](hw4/README.md) for how to place the data pack and run the front end and back end.

- Front end: `hw4/frontend/` (Vite + React + TypeScript)
- Back end: `hw4/backend/` (FastAPI + PydanticAI agent: `prompts/prompt.md`, `agent.py`, `tools.py`, `models.py`)
- Write-ups and evidence: `hw4/output/` (`harness.md`, `design.md`, `usability.md`, `app_check.html`, `audit_trail.json`)
- Prompt log: `hw4/AI_prompts.md`

The course data pack (`campus_customs.db`, product images) and `.env` are not in this repo.
